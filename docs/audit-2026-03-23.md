## Phase 2: Code Review

### 2.1 API Security

| Route | Finding | Severity |
|-------|---------|----------|
| `POST /api/exercises/generate` | No `is_admin` check — any authenticated user can write AI exercises to DB via service-role client | **HIGH** |
| `POST /api/offline/grade-batch` | `exercise_type` and `tense` are free strings (not enums); stored in DB and passed to Claude prompt unsanitized | **HIGH** |
| `POST /api/offline/verb-sync` | `tense` is `z.string()` not `z.enum(TENSES)` — orphan rows possible | MEDIUM |
| `GET /api/offline/module/[id]` | No CSRF, no rate limit; triggers expensive Claude API calls | MEDIUM |
| `GET /api/offline/verbs` | No CSRF, no rate limit; very large payload | MEDIUM |
| `validateOrigin` shared util | Silent passthrough when `NEXT_PUBLIC_SITE_URL` unset in prod — CSRF disabled | MEDIUM |
| `GET /api/streak/calendar` | No CSRF, no rate limit | LOW |
| `POST /api/offline/reports/[id]/review` | No CSRF, no Zod, no UUID validation on path param | LOW |
| `POST /api/tts` | Unbounded in-memory `audioCache` Map — memory leak in non-serverless | LOW |
